# OMR Exam Grader (Web)

โปรแกรมตรวจข้อสอบจากกระดาษคำตอบที่ฝนด้วยดินสอ 2B (OMR) ทำงานในเบราว์เซอร์ล้วน ไม่ต้องติดตั้ง ไม่อัปโหลดไฟล์ไปไหน

## ทำอะไรได้บ้าง

- อัปโหลด **PDF สแกนเฉลย 1 ใบ** + **PDF สแกนกระดาษคำตอบหลายหน้า** (1 หน้า = 1 คน) แล้วได้ **ตารางผล + ไฟล์ CSV**
- **ไม่ต้องตั้งค่าฟอร์ม ไม่ต้องลากกรอบ** — เฉลยเป็นตัวสอนโปรแกรมเองว่าฟอร์มมีกี่บล็อก กี่ข้อ กี่ตัวเลือก
- **หมุนภาพให้เอง** (0/90/180/270°) จากแถบสี่เหลี่ยมดำ สแกนทิศไหนก็ได้ ปนกันในไฟล์เดียวได้
- แยกบล็อกอัตโนมัติ: คำตอบ / ข้อมูลผู้สอบ (รหัสนักศึกษา รหัสวิชา ตอนเรียน → ถอดเป็นตัวเลขต่อกัน) / ช่องดิบ
- **แก้เฉลยในหน้าเว็บได้** ถ้าเฉลยฝนผิด ไม่ต้องสแกนใหม่ และเลือกได้ว่าบล็อกไหนจะใส่ใน CSV
- ให้คะแนนเทียบเฉลย (คะแนนเต็ม = จำนวนข้อที่เฉลยฝน) และชี้ใบที่ต้องตรวจซ้ำพร้อมเหตุผล
- คลิกแถวดูภาพกระดาษที่วงทับช่องที่อ่านได้: เขียว = ถูก, แดง = ผิด, น้ำเงิน = คำตอบที่ถูก, ม่วง = ข้อมูลผู้สอบที่ฝน
- ปรับสัญลักษณ์ตัวเลือกได้ (1-5 / ก-จ / A-E) CSV เป็น UTF-8 with BOM เปิดใน Excel ภาษาไทยไม่เพี้ยน
- ใช้ได้กับ Safari / Chrome; รับไฟล์ภาพ (PNG/JPG) ได้ด้วย (1 ภาพ = 1 หน้า)

## วิธีใช้

1. เปิด `index.html` ในเบราว์เซอร์
2. **ขั้นที่ 1** เลือก PDF เฉลย → ตรวจผลที่อ่านได้ (หัวข้อ "ตรวจเฉลยก่อนยืนยัน") → กด **ยืนยันเฉลย**
3. **ขั้นที่ 2** เลือก PDF กระดาษคำตอบ → รอตรวจ → ดูตาราง / คลิกแถวดูภาพ → **ดาวน์โหลด CSV**

ไฟล์สแกน: สีหรือ grayscale ≥ 200 dpi (ไม่ใช้ขาวดำล้วน) ฟอร์มชุดเดียวกันทั้งไฟล์ ไฟล์ใหญ่ใช้ได้ (ทดสอบ 84 หน้า 118 MB; ตรวจประมาณ 0.3 วินาทีต่อใบ)

PDF.js โหลดจากอินเทอร์เน็ตก่อน ถ้าไม่มีเน็ตจะใช้ `lib/` ที่แนบมา — **ต้องเก็บโฟลเดอร์ `lib/` ไว้ข้าง `index.html`**

## การสแกน

- วางกระดาษหงายหน้า **ทิศไหนก็ได้** โปรแกรมหมุนให้เองจากแถบสี่เหลี่ยมดำ (ขั้นที่ 1 จะบอก "หมุนภาพอัตโนมัติ … °")
- ภาพต้องเห็นแถบดำอย่างน้อย 6 แท่ง (ไม่ตัดขอบ) และครบทั้งแผ่น ไม่มีเงา/รอยพับพาดวงกลม; ไม่รองรับภาพกระจก
- เอียงเล็กน้อยและเลื่อนได้ ใช้เครื่องสแกนและตั้งค่าเดียวกันทั้งเฉลยและกระดาษคำตอบ
- ใช้เครื่องป้อนกระดาษ (ADF) ได้ — ภาพที่ยืดไม่สม่ำเสมอโปรแกรมชดเชยให้ ควรเปิดดู 2–3 หน้าแรกก่อนสแกนทั้งปึก

## การเตรียมเฉลย

เฉลยสอนโปรแกรมทั้งหมด (คะแนนเต็ม โครงสร้างฟอร์ม ชนิดบล็อก) เฉลยผิด ทุกใบผิดตาม ใช้กระดาษคำตอบ **ฟอร์มเดียวกับที่นักศึกษาใช้** แล้วฝนดังนี้

| บล็อก | ฝนอย่างไร | โปรแกรมเข้าใจว่า |
|---|---|---|
| ข้อสอบ | **1 ช่องต่อ 1 ข้อ** เฉพาะข้อที่มีจริง | บล็อกคำตอบ — ตรวจเทียบเฉลย |
| ข้อเกินที่ฟอร์มมีแต่ข้อสอบไม่มี | **ไม่ฝน** | ไม่นำมาคิดคะแนน |
| ช่องรหัส (เลข 0–9 ทีละหลัก เช่น รหัสนักศึกษา) | ไม่ต้องฝนก็ได้ (ฝนเลข 0 ทุกหลัก หรือฝนเลขคอลัมน์ละ 1 ช่อง ก็ได้) | อ่านเป็นรหัส — ไม่ตรวจ แต่ถอดค่าลง CSV |
| ช่องอื่นที่ไม่ฝน (เช่น เพศ) | ไม่ฝน | ช่องดิบ — ส่งออกคำตอบของแต่ละคอลัมน์ต่อกัน (ไม่ฝน = `-`, หลายช่อง = `(a,b)`) |

ข้อควรระวัง: ฝนให้ **เข้มเต็มวง** ห้ามฝนจาง ห้ามมีรอยลบ/รอยเปื้อน ห้ามฝนข้อเดียวหลายช่อง (ข้อนั้นจะถูกข้ามและเตือน) ข้อไหนลืมฝนจะไม่ถูกนับเข้าคะแนนเต็ม ไฟล์เฉลยมี 1 หน้า (หลายหน้าใช้เฉพาะหน้าแรก)

### แก้ผลในขั้นที่ 1 (ไม่ต้องสแกนเฉลยใหม่)
- **ตาราง "เฉลยที่อ่านได้"**: เลือกคำตอบใหม่ของแต่ละข้อ หรือ "–" เพื่อไม่นับข้อนั้น ข้อที่แก้เป็นสีเหลือง คะแนนเต็มคำนวณใหม่ ต้องกดยืนยันอีกครั้ง (การแก้อยู่ในหน้าเว็บ ถ้ากด "วิเคราะห์ใหม่" หรือปรับตั้งค่าขั้นสูง ค่าที่แก้จะหาย)
- **ตาราง "บล็อกที่โปรแกรมพบ"**: เปลี่ยนประเภทบล็อกระหว่าง "ช่องดิบ" / "อ่านเป็นรหัส", ติ๊ก **"ใส่ใน CSV"** เลือกบล็อกที่จะส่งออก (บล็อกที่ไม่ติ๊กไม่ถูกอ่านและไม่ทำให้ใบถูก flag), ตั้งชื่อคอลัมน์ (เช่น รหัสนักศึกษา, รหัสวิชา) บล็อกที่ไม่ใช่คำตอบเรียงซ้าย→ขวา และข้อมูลทั้งบล็อกอยู่คอลัมน์เดียว

### ตรวจเฉลยก่อนยืนยัน
- [ ] **จำนวนบล็อกถูกต้อง** — บล็อกคำตอบ/ข้อมูล/ช่องดิบตรงกับฟอร์มจริง และกรอบสีครอบถูกบล็อก (น้ำเงิน = คำตอบ, ม่วง = ข้อมูลผู้สอบ, ส้ม = ช่องดิบ)
- [ ] **คะแนนเต็ม = จำนวนข้อสอบจริง** และตารางเฉลยตรงกับกระดาษเฉลยทุกข้อ (ข้อที่ขึ้น `–` โดยไม่ควรเป็น ให้แก้ในตาราง หรือกลับไปดูว่าฝนจาง/ซ้ำ)
- [ ] **ภาพที่วงทับ** — ช่องที่ฝนเป็นสีเขียว ช่องว่างเป็นสีเทา วงแดง = หาวงกลมจริงไม่เจอ ใช้ตำแหน่งตามกริดแทน (เช่น วงที่ถูกรอยลบทับ) ไม่กระทบการอ่านเฉลยและคะแนน
- [ ] **คำเตือนสีเหลือง** อ่านทุกข้อ:

| คำเตือน | ความหมาย / วิธีแก้ |
|---|---|
| ข้อที่ไม่นำมาคิดคะแนน: … | ข้อที่ไม่มีเฉลย — ปล่อยไว้ถ้าเป็นข้อเกิน ไม่ใช่ก็แก้ในตารางเฉลย |
| เฉลยข้อ N ฝนหลายช่อง | ฝนซ้ำ/มีรอยลบ — แก้ในตารางเฉลย หรือทำเฉลยใหม่ |
| บางช่องหาวงกลมไม่เจอ | วงจาง/ติดเส้น — ดู "ภาพ debug" หรือปรับ "ความไวต่อขอบวงกลม" |
| ไม่พบเฉลยที่ฝนเลย | เกณฑ์เข้มเกินไป/ฝนจาง — ลดเกณฑ์ความเข้ม |

ปรับ "ตั้งค่าขั้นสูง" แล้วต้องกด **วิเคราะห์เฉลยใหม่** และยืนยันใหม่ทุกครั้ง

### ทดสอบก่อนตรวจจริง (แนะนำ)
ลองกระดาษ 2–3 ใบที่รู้คำตอบ (ฝนตามเฉลย / ฝนผิด / เว้นว่าง) เช็คว่าคะแนนตรงและรหัสอ่านครบ คลิกแถวดูภาพ วงต้องทับตรงช่อง หลังตรวจเต็มชุด เปิด "แสดงเฉพาะใบที่ต้องตรวจซ้ำ" ดูทีละใบ สุ่มเช็คใบ "ปกติ" และเทียบกับการตรวจด้วยตา 5–10 ใบในครั้งแรกที่ใช้ฟอร์มใหม่

## ผลลัพธ์

**ใบที่ต้องตรวจซ้ำ** ขึ้นเหตุผลบรรทัดเดียว รวมหัวข้อเดียวกัน เช่น `ฝนไม่ครบ: ข้อ 25 · ข้อมูล3 (3 หลัก): หลักที่ 1-2 ไม่ฝน` (ฝนหลายช่อง, ช่องรหัสไม่ฝน/ซ้อน, จัดภาพไม่แน่ใจ, หาวงกลมไม่พบ)

**CSV**: `ลำดับหน้า` · บล็อกข้อมูล/ช่องดิบที่เลือก (เรียงซ้าย→ขวา) · `คะแนนรวม` · `คะแนนเต็ม` · `สถานะ` · `ข้อ 1 … ข้อ N` (เลือกได้ว่าเป็นคำตอบที่ฝน หรือ 1/0 ถูก-ผิด; `-` = ไม่ฝน, `*` = หลายช่อง) มีตัวเลือกกัน Excel ตัดเลข 0 นำหน้า

## หลักการทำงาน (สำหรับผู้พัฒนา)

PDF.js แปลงหน้า PDF เป็นภาพ (200 dpi) และ Canvas API อ่านพิกเซล ไม่ใช้ OpenCV

1. **หมุน + หาวงกลม** (`findStrip`, `rotateQuarter`, `detect`) — หาแถบดำสนิทที่เรียงเป็นแนว ≥ 6 แท่งเพื่อหมุนให้แถบอยู่ขอบล่าง; หาวงกลมโดยเทียบกับพื้นหลังรอบๆ (วงบนพื้นชมพูไม่จาง) ตัดเส้นตรงยาวออกไม่ให้ติดวง จดตำแหน่งเส้นตั้งหนา กรองด้วยขนาด/สัดส่วน/อัตราเติม (ตัดสี่เหลี่ยมทึบ) แก้เอียงเล็กน้อยด้วยแนววงกลมข้างเคียง (`estimateAngle`); วัดการฝนจากช่องสัญญาณ maxCh (หมึกสีหาย เหลือดินสอ)
2. **จัดบล็อก** (`buildBlocks`) — เชื่อมวงกลมข้างเคียงเป็นกลุ่ม แยกกลุ่มที่มีเส้นตั้งหนาคั่น ตัดคอลัมน์/แถวที่วงน้อยผิดปกติและวงเดี่ยว (ลายมือ) เติมวงที่หายตามระยะห่างปกติ
3. **เฉลยสอนโปรแกรม** (`analyzeKey`) — ช่องที่เข้มเกินเกณฑ์ (15%) เหนือค่ากลางของหน้า = ฝน แล้วแยกประเภท: ฝนแถวเดียวกันหลายคอลัมน์ หรือคอลัมน์ละ 1 ช่อง (≥ 6 แถว) = ข้อมูลผู้สอบ; อย่างอื่นที่ฝน = คำตอบ; ไม่ฝนเลย: ขนาดเท่าบล็อกคำตอบ = ข้อเกิน, ≥ 10 แถว = รหัส (ข้อมูล), อื่นๆ = ช่องดิบ; ข้อเรียงเลขต่อจากซ้าย→ขวา
4. **จัดภาพใบนักศึกษา** (`alignPoints`) — ได้ตำแหน่งตั้งต้น 2 วิธีแล้วเลือกวิธีที่ดีกว่า: (ก) โหวต + ICP affine (ข) แถบดำขอบล่าง จับคู่แท่งด้วยเส้นตรง x'=a·x+b (ทนแถบขาด/เกิน) บอกการยืดตามแนวป้อนกระดาษ + ยึดแนวตั้งจากตำแหน่งแถบ; ตารางวงกลมซ้ำๆ จึงเลื่อน 1 แถว/คอลัมน์ได้ จึงตรวจ ±1 คอลัมน์ด้วยเส้นตั้งหนา และตัดค่าผิดปกติตอนคำนวณ; ชดเชยเฉพาะที่ด้วยมัธยฐานส่วนต่างของวงข้างเคียง; สุดท้าย **จับคู่แบบกรอบบล็อก** คือจัดกลุ่มวงกลมของใบนั้นเป็นบล็อกแล้วจับคู่ต่อบล็อก (ขนาดเท่ากัน + ใกล้ตำแหน่งที่คาด) ช่อง i,j ของเฉลย = ช่อง i,j ของบล็อกนั้น ไม่เลื่อนแถว/คอลัมน์ ถ้าหาคู่ไม่ได้ใช้ตำแหน่งจากวิธีข้างต้นแทนเฉพาะบล็อกนั้น; จับคู่วงกลมได้ < 60% flag "จัดภาพไม่แน่ใจ"
5. **ตัดสินการฝน/ให้คะแนน** (`pick`, `gradeStudent`) — ช่องที่เกินเกณฑ์ = ฝน ช่องที่จางกว่า 55% ของช่องที่เข้มสุดในข้อเดียวกัน = รอยลบ ไม่นับ; คำตอบ: ฝน 1 ช่อง → เทียบเฉลย, ไม่ฝน/ฝนหลายช่อง → ผิด + flag; บล็อกข้อมูล: คอลัมน์ไม่ฝน `?`, ฝนหลายช่อง `*` + flag; ลำดับแถวนับจาก 0 เป็นเลข (บล็อก ≥ 10 แถว) หรือจาก 1 (บล็อกเล็กกว่า)

## สถานะการพัฒนา

**ทำแล้ว / ทดสอบแล้ว**
- UI 2 ขั้น, หมุนภาพอัตโนมัติ, หาวงกลม/จัดบล็อก/แยกประเภทจากเฉลย, แก้เฉลยและเลือกบล็อกใส่ CSV, ภาพตรวจรายใบ, CSV (UTF-8 BOM), PDF.js สำรองใน `lib/`
- ทดสอบกับสแกนจริง: เฉลย 2 ชุด + กระดาษคำตอบ 25 ใบและ 84 ใบ (ไฟล์รวม) — รหัสนักศึกษา 13 หลัก รหัสวิชา ตอนเรียน อ่านถูก, จับคู่วงกลมได้ ≥ 93% ทุกใบ, ผลเท่ากันแม้จำลองแถบดำขาด/เกิน/ไม่มีแถบ และกับสำเนาเฉลยที่หมุน/เอียง
- แก้ปัญหาที่เจอจากสแกนจริง: ภาพยืดไม่สม่ำเสมอจาก ADF, ตารางวงกลมเลื่อน 1 แถว/คอลัมน์ (เช่นใบ 53, 64, 69)

**ยังไม่ได้ทำ / ข้อจำกัด**
- [ ] ยังไม่ได้เทียบ **คะแนน** กับการตรวจด้วยตาอย่างเป็นระบบ (ตรวจด้วยตาจากภาพซ้อนเป็นบางใบ)
- [ ] ช่อง "ทำข้อสอบชุดที่ ① ②" ไม่ถูกอ่าน — ถ้ามีหลายชุดข้อสอบต้องแยกไฟล์ตามชุดและใช้เฉลยของชุดนั้น

- [ ] ลำดับเลขแถวของบล็อกรหัสสมมติว่าเริ่มที่ 0 จากบนลงล่าง (ฟอร์มอื่นอาจต่างออกไป)

## ข้อควรระวัง
- ขั้นหาวงกลมอัตโนมัติคือความเสี่ยงหลัก (ฟอร์มสีอ่อน เส้นจาง) — มี **ภาพ debug** และตัวปรับ "ความไวต่อขอบวงกลม" ใน "ตั้งค่าขั้นสูง"
- ใบที่ภาพมีปัญหา (ไม่เห็นแถบดำ ตัดขอบ ภาพกระจก) มักขึ้น "จัดภาพไม่แน่ใจ" หรือ "หาวงกลมในหน้านี้ไม่พบ"
